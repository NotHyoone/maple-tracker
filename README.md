# 메이플 트래커

넥슨 Open API로 **이벤트 정보**와 **내 캐릭터 정보**를 하루 3번 자동 수집해서,
게임을 켜지 않아도 휴대폰으로 확인할 수 있는 웹페이지(GitHub Pages)를 만듭니다.

- **내 캐릭터**: 레벨·경험치, 전투력 추이, 주요 스탯, HEXA 코어, 심볼, 장비(스타포스·잠재 등급), 장비·어빌리티·하이퍼스탯 프리셋 1~3(현재 적용 번호 표시, 적용 중 프리셋과 다른 장비 강조)
- **이벤트로 성장하기**: 진행 중인 이벤트를 분류(경험치, 헥사, 심볼, 강화, 버닝 등)하고,
  캐릭터의 현재 상태(부족한 심볼, 낮은 HEXA 코어, 레벨 구간 등)에 맞춰 우선순위와 이유, 받을 보상을 보여줍니다.
- **이벤트**: 남은 기간(D-day), 곧 끝나는 이벤트, 본문에서 뽑은 주요 보상
- **계정·공지**: 계정 캐릭터 목록, 업데이트 공지

## 동작 방식

```
GitHub Actions (매일 08:17 / 14:17 / 22:17 KST)
  └ python -m collector.main
      ├ 이벤트 목록·상세 → data/events/
      ├ 캐릭터 정보 → data/characters/<이름>/latest.json, history.json (일별 기록)
      ├ 성장 가이드 → data/guide.json
      └ web/ + data/app.json → site/ → GitHub Pages 배포
```

- `collector/`: 수집·분석 (Python 3.11+, 표준 라이브러리만)
- `web/`: 화면. 브라우저가 `data/app.json`을 읽어 그립니다 (빌드 도구 없는 바닐라 JS)
  - `js/format.js` 포맷·날짜 계산, `js/store.js` 브라우저 저장소, `js/render.js` 화면 조각, `js/app.js` 진입점
- `tests/`: 화면 로직 테스트 — `node --test tests/*.test.mjs`

하이퍼스탯 프리셋 수집에는 캐릭터당 `character/hyper-stat` 호출이 1회 추가되며, 호출 한도에 걸려도 기존 정보가 먼저 수집되도록 목록 마지막에 호출합니다. 장비·어빌리티 프리셋은 기존 응답에서 가져와 추가 호출이 없습니다.

목표·시세 같은 개인 설정은 **브라우저에만 저장**되고 저장소에는 올라가지 않습니다.
기기를 옮길 때는 `계정·설정` 탭의 백업 내보내기/가져오기를 쓰세요.

## 설정

1. **API 키 등록**: 저장소 `Settings → Secrets and variables → Actions → New repository secret`
   - Name: `NEXON_API_KEY`
   - Secret: 넥슨 Open API 키
2. **Pages**: `Settings → Pages → Source: GitHub Actions`
3. **수집할 캐릭터**: `config.toml` 의 `names` 수정 (비우면 레벨 상위 `auto_top`명 자동)
4. 첫 실행: `Actions → 메이플 정보 수집 → Run workflow`

## 디스코드 알림

종료 3일 전·1일 전 이벤트와 새로 시작한 이벤트를 디스코드로 알려줍니다. 알림에는 기간, 주요 보상,
성장 가이드 기준으로 "챙기면 좋은 캐릭터"가 함께 들어갑니다. 같은 알림은 다시 보내지 않습니다(`data/notify_state.json`).

1. 디스코드 채널 설정 → 연동 → 웹후크 → 새 웹후크 → 웹후크 URL 복사
2. 저장소 `Settings → Secrets and variables → Actions → New repository secret`
   - Name: `DISCORD_WEBHOOK_URL`, Secret: 복사한 URL
3. 연결 확인: `Actions → 메이플 정보 수집 → Run workflow`에서 **디스코드 테스트 메시지만 보내기**를 체크하고 실행
4. 알림 기준·멘션은 `config.toml`의 `[notify]`에서 바꿉니다.

## 로컬 실행

```bash
export NEXON_API_KEY=발급받은키
python -m collector.main            # 수집 + 페이지 생성
python -m collector.main --site-only  # 저장된 데이터로 페이지만 다시 생성
python -m http.server -d site       # http://localhost:8000 에서 확인 (파일 직접 열기는 안 됨)
```

## 목표 계산과 수치표 (`web/rules/`)

`목표` 탭에서 캐릭터별로 레벨 / HEXA 코어 / 심볼 목표를 정하면 남은 양과 예상 기간을 계산합니다.
계산에 쓰는 게임 수치는 확인된 값만 넣고, 비어 있는 표는 화면에 "미확인"으로 표시합니다.

| 파일 | 내용 | 출처·검증 |
|---|---|---|
| `rules/level.json` | 200~299레벨 필요 경험치 | devcomma 경험치 계산기 표. API 실측 7개 레벨과 측정 오차 이내 일치 |
| `rules/symbol.json` | 심볼 성장치·강화 메소·일일 지급량 | 아케인·어센틱 성장치: API 실측 일치. 강화 메소: 인벤 심볼 강화표(아케인은 계산기 공식과 114개 전부 일치, 지역 합계 일치). 일일 지급량: 넥슨 공식 가이드. 그랜드 어센틱 성장치는 미확인 |
| `rules/hexa.json` | HEXA 코어 솔 에르다·조각 | 솔 야누스만 계산기 표(출처 1곳). 스킬·마스터리·강화 코어는 패치로 여러 번 바뀌어 현재 기준 표 미확인 |

### 시세와 필요 메소

목표 탭 맨 위 **시세** 카드에 솔 에르다 조각 가격(만 메소)과 메소 시세(1억 메소당 메이플포인트)를 입력하면
목표마다 필요 메소와 현금 환산값, 캐릭터별 합계가 표시됩니다.
공식 시세 API가 없어 직접 입력하며, 입력 날짜를 함께 저장해 14일이 지나면 갱신 알림을 띄웁니다.
솔 에르다는 거래가 안 되므로 메소로 환산하지 않습니다.

### 설정 프리셋

목표 탭 맨 위에서 현재 목표와 시세를 이름 붙여 저장하고, 불러오거나 삭제할 수 있습니다.
불러오면 현재 목표와 시세를 덮어쓰며, 프리셋에 시세가 없으면 기존 시세는 유지합니다.
프리셋은 **브라우저에만 저장**되며 백업 내보내기에 포함됩니다.

### 스타포스 기댓값 (`rules/starforce.json`)

목표 탭에서 `스타포스` 목표로 장비와 목표 성급, 조건(스타캐치, 파괴 방지, 이벤트, MVP/PC방, 복구용 장비 가격)을 고르면
평균 메소·파괴 횟수·시도 횟수와 파괴 없이 성공할 확률을 정확히 계산하고(연립방정식),
모의 시행 1만 회로 운에 따른 비용 구간(상위 10% / 중간값 / 하위 10% / 최악 1%)을 보여줍니다.
진행 중인 이벤트 공지에 스타포스 할인·파괴 감소 등이 있으면 자동으로 반영합니다.

| 항목 | 출처·검증 |
|---|---|
| 15~29성 확률 | 넥슨 테스트월드 '스타포스 개편' 공식 표 |
| 스타캐치 (성공 ×1.05, 유지:파괴 비율 유지) | 넥슨 공지 15성 예시와 일치, 인벤 분석글과 일치 |
| 15성 이상 비용 공식 | devcomma 계산기 코드와 인벤 테섭 분석글의 성급별 제수가 일치 |
| 파괴 방지 (15~17성, 기본 메소 200% 추가) | 넥슨 공식 |
| 0~14성 확률, 10~14성 비용, 파괴 후 흔적 복구(22성 상한, 같은 장비 1~4개) | devcomma 계산기 (출처 1곳) |

### 잠재능력 기댓값 (`rules/potential.json`, `rules/potential_meta.json`)

목표 탭에서 `잠재능력` 목표로 장비, 윗잠/에디셔널, 목표 등급, 옵션 조건(주스탯 %, 공·마 %, 공·마%/보공/방무 유효 줄,
크뎀, 쿨감, 드롭·메획 등)을 고르면 1회 확률, 평균 재설정 횟수·메소, 운에 따른 비용 구간을 보여줍니다.

- 줄별 옵션 확률: 넥슨 공식 확률 공개의 '확률 검색' 결과. 세 줄 조합을 모두 나열해 정확히 계산하고, 공식 중복 제한 규칙을 반영
- 등급 상승 확률·천장: 넥슨 공식 확률 페이지
- 메소 재설정 비용: 윗잠은 넥슨 공식 업데이트 공지 표, 에디셔널은 계산기(출처 1곳)

확률표는 내 장비의 (부위, 레벨) 조합만 받아 둡니다. 장비를 바꿨다면 다시 받으세요(요청 사이 1초 대기).

```bash
python -m collector.fetch_potential
```

### 내 운 vs 기댓값 (`기록` 탭)

넥슨 API의 스타포스·큐브·메소 잠재능력 재설정 사용 기록을 모아 실제 결과를 확률 모델과 비교합니다.

- 저장소가 공개일 수 있어 **원본 기록(아이템 이름, 시각, 기록 ID)은 저장하지 않고** 날짜별 집계 숫자만
  `data/history/YYYY-MM.json`에 저장합니다 (예: 17성 스타캐치 성공 시도 12회 → 성공 2, 파괴 1).
- 기록은 2023-12-27부터 조회할 수 있고, API 호출 한도 때문에 실행마다 20일씩 과거로 채웁니다(코드 푸시 때는 API를 쓰지 않고 화면만 다시 배포)(`config.toml`의 `[history]`).
- 스타포스는 2025-04-01 이후, 이벤트·찬스타임·슈페리얼을 뺀 기록만 비교합니다. 잠재능력은 천장 확정·미라클 타임을 뺍니다.
- 운은 시도마다 확률이 달라도 되도록 기대값·분산을 합친 정규근사로 "상위/하위 N%"를 계산합니다.

`data/observed_exp.json`은 수집기가 캐릭터의 경험치와 경험치%로 그 레벨의 필요 경험치를 역산해
자동으로 쌓는 값입니다(오차 0.01% 이하). 계정 부캐 중 아직 측정 안 된 레벨도 실행마다 몇 명씩 조회합니다.

## 성장 가이드 규칙 바꾸기

`collector/growth.py`
- `CATEGORIES`: 이벤트 분류 키워드. 새 이벤트 유형이 잘못 분류되면 키워드를 추가하세요.
- `reasons_for()`: 분류별로 캐릭터에게 얼마나 중요한지(점수 0~5)와 이유.
